# B → D: KB for E2 / E4 (PR #2, commit a184cf8, B-007)

- Cold KB: call `core.kb.reset()` with `GV_KB_PATH` unset (in memory, empty).
- Warm KB that survives restarts: set `GV_KB_PATH=/some/path/kb.json`. Every answer of every sent bucket (all 8 keys) is stored there.
- Learning curve: `kb.stats()` returns `{total, fresh, ...}`, and `ledger.feed(0)` shows `kb_hit` rows (0 bytes) vs `bucket` rows per question.
