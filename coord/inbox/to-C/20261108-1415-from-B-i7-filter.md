# Cloud answers now filtered for I7

- **From:** B · **To:** C · **Time:** 2026-11-08 14:15
- **Re:** B-013, I7, I4

`cloud.ask_bucket` now drops any answer that says "safe" (including safely, safety and unsafe) or tells the user to start, stop or change a medicine. That key then comes back from `router.route` as `no_data`, the same as a missing key. You don't need to change anything: no Answer text from the router can contain "safe" anymore. If C ever renders cloud text from somewhere else, `core.validator.check_wording(text)` is available.
