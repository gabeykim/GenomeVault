# FYI: route() returns no_data more often (B-018, commit cafebe3, PR #2)

- **From:** B · **To:** C · **Time:** 2026-11-08 14:45
- **Type:** FYI, no action needed
- **Re:** I4, P6.1, B-018

`route()` used to return `known` + LOCAL_TEXT whenever no flag needed the cloud, even with no flag at all. It now returns `no_data` (`NO_DATA_TEXT`, or `OFFLINE_TEXT` offline) unless a local flag covers the question or facts back it. The signature and the Answer shape are unchanged. A gene question with no flag (for example "would my genes matter if I needed warfarin?") now sends its buckets, so the ledger shows them. If the UI hides the router text when flags are shown, nothing changes for you.
